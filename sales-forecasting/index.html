About this demo How the forecast works +

This demo compares four forecasting approaches using sales data directly in your browser:

  • Naive forecast: Uses the last observed value for future points.
  • Moving average: Averages the previous three months to smooth short-term fluctuations.
  • Linear regression: Fits a straight-line trend to capture overall growth or decline.
  • Quantile-filtered regression: Removes outliers using the interquartile range (IQR) before fitting a trend.

Mean Absolute Percentage Error (MAPE) is calculated for each method on the test data, and the best-performing approach is highlighted. CSV uploads can contain up to 100 rows.
